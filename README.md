E-Commerce System Project
Overview

This project is a simple E-Commerce Management System developed in Python using Object-Oriented Programming (OOP). The system allows users to register, log in, browse products, add items to a shopping cart, and complete purchases. It also includes an administrator panel for managing products.

Features
User Features
User Registration
User Login Authentication
View Available Products
Add Products to Shopping Cart
View Shopping Cart
Checkout and Complete Orders
Automatic Order Recording in a Text File
Admin Features
Add New Products
Delete Existing Products
View Product Inventory
Password-Protected Admin Access
Technologies Used
Python 3
Object-Oriented Programming (OOP)

Workflow
User registers an account.
User logs into the system.
User browses available products.
User adds products to the cart.
User reviews the cart and total cost.
User completes checkout.
Order information is saved in orders.txt.
Administrator can add, delete, and manage products.
